# Timeless Art Gallery

A premium art gallery showcasing original paintings, photography, and digital art from talented artists around the world.

## Features

- Responsive design for all devices
- Interactive gallery with hover effects
- Artist showcase section
- About and contact sections
- **New Shopping Cart Functionality**
  - Browse available artworks
  - Add items to cart
  - Adjust quantities
  - Remove items
  - Checkout process

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- JavaScript (ES6)
- Font Awesome icons

## How to Use

1. Clone this repository
2. Open `index.html` in your browser
3. Click "Shop Now" to browse and purchase artworks
